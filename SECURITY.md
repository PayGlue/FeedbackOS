# Security Policy

This policy covers FeedbackOS, PayGlue's fork of Quackback, and the instance
running at hub.payglue.io and docs.payglue.io.

## Reporting a Vulnerability

Please do **not** open a public GitHub issue.

- **Email** a report to [team@payglue.io](mailto:team@payglue.io) with a
  description, steps to reproduce and the potential impact, or
- **open a [private security advisory](../../security/advisories/new)** in this
  repository.

We aim to respond within 24 hours and keep you updated while we work on a fix.

A vulnerability that also affects the original project belongs upstream as
well: report it to Quackback through its own security policy.
